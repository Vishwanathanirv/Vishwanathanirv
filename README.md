I build things for fun. Security is what keeps pulling me in.

Each one has a live demo with no sign-up, and ships a threat model (`SECURITY.md`) that says what it does not protect against.

| Build | What it does |
| --- | --- |
| [Airlock](https://llm-firewall-liard.vercel.app) | A firewall for LLM apps: blocks prompt injection, redacts secrets, catches leaks in replies |
| [Redline](https://redline-config-auditor.vercel.app) | Reviews Dockerfiles, Compose, Kubernetes, nginx and sshd configs, and writes the fix |
| [PacketEye](https://packeteye.vercel.app) | Network intrusion detection from live capture or pcap, with every alert explained |
| [Lamplight](https://home-network-guardian.vercel.app) | Finds every device on your home network and lists what to fix tonight |
| [MedVault](https://medvault-five-pi.vercel.app) | Hides an encrypted medical record inside the patient's own scan image |
| [FraudLens](https://online-payment-fraud-detection-ruby.vercel.app) | Fraud-operations workbench: thresholds, staffing, backtests, on your own data |
| [Rehearse](https://ai-mock-interviews-v2-gules.vercel.app) | A voice interviewer that follows up on what you missed |
| [Tide-Weaver](https://tide-weaver.vishwanathanirv.workers.dev/) | A free browser game: surf endless waves, every dive plays a note |
